# 判定由允收標準推導，不由 AI 直接給出

本專案要解決的痛點是「判定標準不一」。若讓 AI 直接輸出 Pass / Warning / Fail，判定依據不可追溯、且隨 prompt 措辭漂移，等於把人工目檢的不一致換成 AI 的不一致。因此 AI 只負責從**檢驗規範**的**缺陷分類表**中選出缺陷代碼與程度，**判定**由系統依該版**允收標準**以規則推導，並記錄規範版本，使每筆判定都能回答「為什麼是這個結果」。

## Considered Options

- 自由文字 custom criteria + AI 直接判定（原設計）：最省工，但重現了痛點，且缺陷描述無法彙總成柏拉圖與趨勢。
