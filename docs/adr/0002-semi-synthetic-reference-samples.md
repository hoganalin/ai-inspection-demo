# 標準樣本集採用半合成影像

一致性分析 (MSA) 的前提是每個樣本的**標準答案**——包含缺陷分類與**程度**——必須可信且已知。查到的公開晶片缺陷資料集要嘛未公開或需付費、無授權條款，要嘛是封裝 IC 而非裸晶粒，且都只有類別標註、沒有尺寸，無法支撐量化的**允收標準**。因此改以 CC 授權的真實晶粒照片為底圖，用程式注入已知位置與尺寸的缺陷，並在作品中明示為合成；真實導入時標準樣本應由 QA 自產線挑選並經量測確認。

## Considered Options

- MVTec AD（CC BY-NC-SA 4.0）：可信但非晶粒、無程度資訊，需改情境。
- 付費資料集（lonlonago，$89）：無授權條款、為封裝 IC、無程度資訊。
