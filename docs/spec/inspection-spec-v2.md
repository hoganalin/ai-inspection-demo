# 檢驗規範 v2 — 晶粒外觀檢查

> 規範版本：`v2` ・ 生效：2026-10-06 ・ 所有數值為**假設值**（模擬情境，非業界標準）。用詞依 [CONTEXT.md](../../CONTEXT.md)。
> 修訂依據：v1 的一致性分析（[msa-summary.md](../../experiment/results/msa-summary.md)）發現漏判主因是「看不到」與「量不準」，不是規則本身。v2 只改影像取得、量測方式與安全路由；**缺陷分類與允收門檻沿用 [v1](inspection-spec-v1.md) 第 1–4 節**。規則實作見 `experiment/spec_v2.py`。

## 1. 影像取得：分塊放大判讀

一顆晶粒（1000 × 1000 px，5 µm/px）切成 36 張放大影像，同一次判讀一起看：

| 影像 | 範圍 | 放大 |
| --- | --- | --- |
| 1–8 | 上緣帶：距上緣 0–60 px，由左到右每段 125 px | 4 倍 |
| 9–16 | 右緣帶：距右緣 0–60 px，由上到下 | 4 倍 |
| 17–24 | 下緣帶：距下緣 0–60 px，由左到右 | 4 倍 |
| 25–32 | 左緣帶：距左緣 0–60 px，由上到下 | 4 倍 |
| 33–36 | 核心區四個象限（左上、右上、左下、右下，各 500 × 500 px） | 2 倍 |

邊緣帶 60 px 涵蓋周邊區（0–20 px）、seal ring（20–24 px）與 pad 列（40–56 px）。40 µm 的崩角在全幅影像上只有 8 px，放大 4 倍後為 32 px。

## 2. 量測：只框選，不估尺寸

判讀者（AI 或人）只回報**缺陷代碼**與在該張影像上的**框選範圍**（左上、右下座標）。下列各項由系統依框選範圍換算回原影像座標後計算：

| 項目 | 換算方式 |
| --- | --- |
| 檢驗區域 | 框內最深入晶粒的點距最近邊緣 ≤ 20 px → 周邊區；否則核心區 |
| `CHP` 深度 | 自最近邊緣向內到框的最深處（µm）；> 20 px 即觸及 seal ring，> 24 px 即延伸進核心區 |
| `SCR`／`CRK` 長度 | 框的對角線長度（µm） |
| `SCR` 是否經過 pad | 框與任一 pad 範圍重疊 |
| `CON` 直徑 | 框的長邊（µm）；每顆各框一個 |

同一缺陷在多張影像被框到時，同代碼且框重疊（或相距 3 px 內）者合併為一個。

## 3. 安全偏向的路由（在 v1 允收標準之上）

| 情況 | v2 判定 | 理由 |
| --- | --- | --- |
| 周邊區有任何 `CHP`／`CRK`／`CON` | 至少 Warning | 周邊區小缺陷最常被漏看，寧可送人工複判 |
| 核心區的線狀缺陷（`SCR`／`CRK`） | 至少 Warning | v1 中 `CRK` 常被看成 `SCR`；混淆時取嚴 |
| 一次回報 ≥ 4 顆 `CON` | `CON` 不直接 Fail，送人工複判（Warning） | 大量顆粒多為把電路色塊誤認，是幻覺的典型型態 |

`CRK` 任何長度仍為 Fail；其餘依 v1 允收標準。一顆晶粒的判定取所有缺陷中最嚴重者。

## 4. 判讀回覆無法解析

格式不符（影像編號、缺陷代碼或框選座標不合法）→ 判定 Warning，送人工複判，不補任何數值（同 v1）。
