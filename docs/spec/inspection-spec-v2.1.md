# 檢驗規範 v2.1 — 晶粒外觀檢查

> 規範版本：`v2.1` ・ 凍結：2026-10-13（git tag `spec-v2.1-frozen`）・ 所有數值為**假設值**（模擬情境，非業界標準）。用詞依 [CONTEXT.md](../../CONTEXT.md)。
> 修訂依據：v2 的誤判（應放行卻退件 7.6%）全部來自框選過大、尺寸高估（例：8 µm 的崩角量成 56 µm）。v2.1 **只改量測**；影像取得（36 張分塊放大）、判讀者回報內容（缺陷代碼＋框選範圍）、缺陷分類與允收門檻都沿用 [v2](inspection-spec-v2.md) 與 [v1](inspection-spec-v1.md)。規則實作見 `experiment/spec_v21.py`。

## 1. 量測：框只決定「在哪裡找」

1. 判讀者的框向外放寬 12 px，當作搜尋範圍。
2. 系統把範圍內的影像和**標準晶粒**（golden die）比對：崩角、裂紋找比良品暗的像素，刮傷、污染找比良品亮的像素（污染的陰影不算尺寸）。
3. 用差異像素的實際範圍（取半高寬，排除反鋸齒邊與淡光暈）換算區域與尺寸，換算方式同 v2 第 2 節。

標準晶粒由開發集中 13 張無缺陷良品逐像素取中位數建立（`experiment/golden/golden-die.png`），凍結後不再改。

## 2. 判定路由

| 情況 | 判定 |
| --- | --- |
| 系統在搜尋範圍內找不到差異（尺寸無法確認） | Warning（送人工複判） |
| 尺寸已確認，且落在任一允收門檻 ±10% 內 | Warning（門檻附近交給人） |
| 尺寸已確認，且離所有門檻夠遠 | 依 v1 允收標準判定 |
| 裂紋、刮傷經過 pad、崩角觸及 seal ring 或進入核心區 | 依 v1 直接 Fail（不套用 ±10%） |

v2 的「周邊區崩角／裂紋／污染一律至少 Warning」「核心區線狀缺陷一律至少 Warning」是為了補判讀者量不準而加的；v2.1 改由系統確認尺寸，這兩條不再適用。一次回報 ≥ 4 顆污染只送人工複判的防呆沿用 v2。

## 3. 驗證方式：開發集與盲測集

- **開發集**：原本的 40 張標準樣本（S01–S40）。v2.1 的參數依它調整，所以它的結果**不能**當作成效。
- **盲測集**：凍結後才產生的 40 張新樣本（B01–B40）。缺陷種類與數量沿用開發集的設計，每個缺陷尺寸 × U(0.85, 1.15)，位置與亂數全部重抽；亂數種子取自凍結 commit 雜湊的前 8 碼，凍結前無法預知。
- 判讀者端完全不變：同提示、同 3 位模擬評估者、同模型、每張 2 次。作者本人也依規範判盲測集兩輪，兩輪分在不同天。
- Gate ②→③ 標準不變（漏判率 ≤ 5%、重複性 ≥ 90%、人工複判率 ≤ 30%、評估者間一致率 ≥ 90%、對標準答案一致率 ≥ 90%、誤判率 ≤ 3%），只看盲測集。

## 4. 限制

標準樣本是半合成影像，每張底圖相同、只差光照與雜訊，所以和標準晶粒比對在這裡會比真實產線準。真實晶粒之間有製程差異與對位誤差；導入時須以實際良品重建標準晶粒，並重新驗證。
